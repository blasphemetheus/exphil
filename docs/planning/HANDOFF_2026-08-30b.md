## 5. Gotchas / operational law (new this session; older in HANDOFF_2026-08-30 §5)

- **Never `term_to_binary` a big capture** — 2 GB external-term limit;
  stream raw binaries per item and gather with `:binary.part` (§4.3).
- **Head refits carry the full loss recipe** from the source
  `*_config.json`; plain-CE refits produce plausible val losses and
  degenerate play (§4.3).
- **AR-head sampling must stay ONE fused program** — the eager-glue
  version was 24 ms/decision. Benchmark any sampler change with the
  inline loop (2.53 ms reference).
- The Agent's "Autoregressive controller head ACTIVE" banner is
  **Logger.warning** on purpose: eval protocols run at :warning and
  `arhead_score.sh` greps the run logs for it as a knob assertion.
- `Heads.build_autoregressive` (the old dead prev_* path) is GONE;
  "autoregressive" in configs now means the `--head autoregressive` head;
  `:independent` is the default and what every pre-08-30 checkpoint is.
- Checkpoint `config.head` may round-trip as a string — loaders accept
  both (`agent.ex`, `activations.ex` `checkpoint_head/1`).
- Raw `.slp` header reads (python, beam-free) are the fast way to audit
  corpora: raw element at offset 11+4, the 0x35 size byte INCLUDES
  itself, Game Start chars at `gs+0x65+0x24*i`, types at `+0x66`
  (type 3 = empty). Used for E1 and the D2 artifact.
- loop_report group MEANS are not robust to one degenerate game; session
  dirs need stub + degenerate filters (task 6).
