## Debugging lessons worth keeping (paid for today)

- Enumerate INPUT CLASSES first (HtDP): the datagram grammar test
  battery found in minutes what live-run bisection missed for hours.
  When a live system defies 5+ falsified hypotheses, STOP and write
  the format/contract tests.
- Read the TARGET's verbatim source (WebFetch raw GitHub), not a
  sibling implementation: Ishiiruka ≠ mainline in exactly the byte
  that mattered.
- pkill -f in compound commands self-matches pattern text ANYWHERE in
  the command line (incl. cd paths) — run pkill ALONE, bracket-idiom
  everything ("[d]olphin-emu").
- strace needs a LIVE pid and root (yama); /proc/net/unix and
  :socket.info counters + a raw-frame ring answered instead.
