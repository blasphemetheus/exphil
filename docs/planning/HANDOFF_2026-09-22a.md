## 5. Gotchas / operational law (will silently break the next session)

- **`systemd-run --user` runs the unit from `$HOME`.** A `cd` outside the
  quoted command does nothing; relative paths make the unit die instantly
  with no log. Bit me 4× today. ALWAYS launch via
  `scripts/launch_unit.sh UNIT 'mix run …'` (cd inside, waits 8 s, prints
  status + log tail) or `scripts/launch_coach_unit.sh` for coach reviews.
  For two commands in one unit: `launch_unit.sh U 'bash -c "A && B"'`.
- **One EXLA process on the GPU at a time.** Two agents at once → cuBLAS
  OOM (`Failure to initialize cublas may be due to OOM`). The GA unit and
  the R2 smoke each want the GPU. To co-run, launch with
  `EXLA_MEMORY_FRACTION=0.45` (config/runtime.exs honours it) — untested
  today, TBD.
- **Never regex-edit code with perl/sed using `|` as the delimiter when the
  code contains `||`**: `\|\|` becomes an empty alternation and rewrites
  EVERY line (destroyed index.html once; recovered from git). Use the Edit
  tool or a node patch script with literal anchors (`s.includes(anchor) ||
  throw`), then syntax-check (`node -e 'new Function(...)'`,
  `elixir -e Code.string_to_quoted!`). Saved as memory
  `feedback_no_perl_pipe_delimiter.md`.
- **Chrome automation tabs are `hidden`:** rAF playback never advances and
  timers throttle to 1 Hz. Verify viewer behaviour with
  `viewer.setFrame(i)` and message chains, not by pressing play.
