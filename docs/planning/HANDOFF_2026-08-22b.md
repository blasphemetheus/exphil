## Hard-won lessons (do not relearn)

- **The RNG "canary" does NOT tick at a settled menu** (advances per
  random call, not per frame). Liveness = `MemoryWatcher.traffic/1`
  deltas ONLY. Settled menu memory is genuinely static — dolphin's
  bare-NUL empty steps there are honest.
- **64KB recv buffer is load-bearing**: batch watching composites
  ~20KB frames; the old 2KB buffer truncated them and the parser
  dropped every update while traffic stayed healthy.
- **All of MEM1 churns ~93k words ambiently** (audio/render) even
  when the menu region is static — dump-diff MUST subtract an
  ambient baseline (diff(press) minus diff(ambient) offsets).
- MEM1 discovery: validate with a KNOWN value (scene word at
  +0x479D30). A permissive validator matched a zero-filled heap.

  Monitor's `tail` if the pattern appears in the log path. Bracket
  everything, run pkill alone.
