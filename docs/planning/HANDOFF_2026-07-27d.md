## Interp session (same night, post-farm) — c's open problem 2 SOLVED

Contrastive init forensics ran (user-directed; full ledger + findings:
[INIT_FORENSICS_OPTIONS.md](INIT_FORENSICS_OPTIONS.md)). Headlines:

1. **The crouch absorber is a HELD-B fixed point** (edges, not levels —
   failed seeds press B forever, which is a no-op). Failure = never
   learning to RELEASE conditioned on prev-B. Taxonomy: hold-B (g,h,j),
   silent (e,f), oscillator (l).
2. **Flat T-rescue curve explained quantitatively**: p(release) =
   1 - sigmoid(~0.35/T) = 0.24-0.41 across T=0.3-1.0.
3. **Mental rollout** (`probe_basin_rollout.exs`): offline basin
   simulator, no Dolphin. Three tiers: universal escapers (a,c,i),
   self-consistent (b,d,k), absorbable (rest). 9/12 live prediction;
   this is the option-6 early-reject candidate (per-epoch escape
   fraction).
4. **Mode connectivity**: escape and absorbed solutions are separate
   loss basins (a<->g interior fully absorbed; a<->c connected
   on-manifold).
5. **TRAINING BUG, actionable**: synthetic crouch tails train with the
   prev-action channel ABSENT (duplicate frame numbers break prev
   threading in precompute_frame_embeddings). The release-conditioning
   signal was invisible in exactly the states it matters — escape seeds
   learned it from af parity by luck. One-line fix in RecoverySynth
   (renumber tails); PREDICTION: escape rate >> 6/12. **This is the top
   queue item now.**
