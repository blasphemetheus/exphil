## Ops learned

- Snippet miner assumed port 1; **netplay scrambles ports per session**
  (bot on 1 in 6 games, 2 in 6, plus Fox mirrors). Mining a fixed port
  harvests the HUMAN's frames — now resolved per replay via
  `--bot-code EXPH#288` against `PlayerMeta.netplay_code` (fullwidth `#`).
- `--replays` silently matched nothing for comma lists while reporting
  success; truncated 1-frame replays crash anchor loops. Both fixed.
- `pkill -f` self-match is real: it killed my own shell (exit 144) during
  the session. Use the bracket trick; the lint covers repo scripts only.
- Don't chain `C-c` + a new launch in one tmux command — the stray signal
  killed a live netplay game. Verify the pane is at a prompt first.
