## 5. Gotchas / operational law

- **No `mix` and no `lib/*.ex` edits while `exphil-awbc-arms` is active.**
  Check: `systemctl --user is-active exphil-awbc-arms`. Parse-check scripts
  with `devenv shell -- elixir -e 'Code.string_to_quoted!(File.read!("X"))'`.
- Long runs: `systemd-run --user --unit=<name> --working-directory=$PWD
  --collect -p StandardOutput=append:<log> -p StandardError=append:<log>
  devenv shell -- mix run ...` (Bash tool SIGTERMs at ~10 min; needs
  `dangerouslyDisableSandbox`). Watch with a Monitor on the log.
- `grep` in fish/bash here: patterns starting with `-` need `-e`; `command`
  prefix for coreutils (rust aliases); fish errors on unmatched globs.
- `Nx.Random.split/2` returns a `{parts, 2}` TENSOR, not a tuple — use
  `Nx.Random.fold_in(key, i)` for subkeys (the critic scripts do).
- `Agent.get_controller` debounces same-frame calls — never use it to draw
  multiple samples; use `get_action_with_confidence` → `action.logits.*`.
- `Activations.capture_replay` rows are aligned to `frames[window-1 ..]`
  (`frame_offset`); `load_heads_only` takes `%{"trunk" => acts}` and returns
  a 6-tuple of logits.
- Replays from `--replay-dir X` land in `X/2026-08-Mainline/`; a
  page-aligned `.slp` size = truncated (GOTCHA #102); `--replay-dir` scorers
  must exclude ~100 KB CSS-restart stubs.
- Output.config writes an ANSI reset between label and value (GOTCHA #103):
  strip ANSI before grepping logs (`sed -E 's/\x1b\[[0-9;]*m//g'`), and
  `tr '\r' '\n'` for progress lines.
- A `--resume` now hard-fails on embedding-width mismatch: pass the
  checkpoint's exact embedding flags (incl. `--stage-internals`).
- Do not `ls -l ~/decider2_archive` (file sizes unblind the transfer-decider arms).
