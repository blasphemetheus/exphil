## READ FIRST — rules that save you from wasted sessions

1. **≥3 live RUNS per policy AND ≥3 TRAINING SEEDS per intervention.**
   Yesterday's scheduled-sampling "win" (90/min) died BOTH ways today:
   0 / ~1 / 7-56 self/min across three seeds of the identical recipe.
   Use `scripts/eval_live_protocol.sh`; re-run the same train command for
   a new seed (init randomness is per-process; data seed is fixed at 42).
2. **Staleness is a per-run health stat; loadavg does NOT predict it —
   machine uptime state does. REBOOT before measurement blocks.** After
   today's reboot: 0.2-2% staleness all day even at loadavg 4-6. The
   pre-reboot machine (15h up) gave 17-31% at the SAME loadavg. >10% =
   degraded run, discard. 50%+ (saturating load) = uninterpretable, a
   9-frame cycle can't execute through 20-frame action freezes.
3. **The `mix` hazard, extended:** eval_live_protocol.sh invokes `mix run`
   per run — editing `lib/*.ex` while a block runs injects your code into
   its next run (the 2026-07-15 failure mode). Edit docs/`.exs`-not-called
   only; lib edits and `mix` wait for the block to finish.
4. **`ExPhil.Training.Output` writes to STDERR** — `2>/dev/null` eats
   everything.
5. **The eval OPPONENT is part of the input distribution** (item 0c-5):
   idle-opponent evals only mean something for policies that survive the
   shift — and clean-harness idle evals of a MARGINAL policy have WIDE
   spread (7-56/min on one binary), because absorption time is luck.
   ~20% of runs lose their replay to the SD flake; budget runs for it.

## The theory that organized the day: absorbing states

The policy+game closed loop has a narrow limit cycle (the multishine) and
large-basin fixed points. Botched shine -> shorthop -> land holding down ->
**Squat/SquatWait forever at 0.97 confidence** (the crouch absorber; one
measured spell: 3448 consecutive frames, 78% of the game). Off training
support, the policy emits the marginal-mode action ("down"), which is
self-reinforcing. Everything below follows from this model, and it
predicted every experimental cell correctly.

Repeat-of-crouch is crouch — repeat noise is inert in a fixed point.

confidence). BUT on a functioning policy (`ms_crouch_b`) T=0.5 is

for pathological policies, not an enhancer. Untried: adaptive T (sample
only when recent actions look pooled).
