## 7. Operational laws (new this session)

- **`pgrep -c` prints "0" for zero matches AND exits 1** — so
  `pgrep -c ... || echo 0` captures `"0\n0"`, and `[ "$d" -eq 0 ]` fails on the
  non-integer. Never guard `pgrep -c` with `|| echo 0`. (Cost: a sweep waited
  6h on a quiet machine and aborted.)
- **Clear stale markers before relaunch** — a leftover `.sweep_done` from an
  aborted run made the relaunch monitor fire on old content. Wrappers now `rm
  -f` the marker at start; `.sweep_done`/`.bracket_done` are gitignored.
- **`SECONDS` is a bash special variable** — `${SECONDS:-120}` = 0. Use
  non-colliding names (e.g. `GAME_SECONDS`).
- **Named `defp` called with `fn.()` syntax** (`sf.(0)`) is "undefined
  variable" — call it `sf(0)`.

Standing from 08-26: NO-MIX law; long runs need `systemd-run --user`;
never `2>/dev/null` a long script; deterministic decode is not neutral;
`command` prefix for coreutils; score chains from `.slp` only.

## ADDENDUM (08-28, later session) — the buttons sweep was NOT null

`eval_runs/0828_loop_rescore/RESULTS.md`. New instrument
(`ExPhil.Interp.LoopStats` + `scripts/loop_report.exs`), 85 banked
replays rescored, **no new games, no GPU**.

§4's verdict is **partially retracted**: the buttons sweep was null on
the metric it used, not on the data it collected. Rescored on d_up
press rate, the four arms separate with **disjoint ranges**, monotone,
3.83x end to end (T=0.5 → 112/min, 1.0 → 430/min). Executed taunts,
the rare version of the same pathology, still don't separate — which is
the power argument demonstrated inside one dataset.

The new metric holds within ~±10% across three days/opponents where
armed/min swung 7x, so it can carry an A/B. It has anchored endpoints:
the known-bad argmax runs score frozen-input 0.98–0.99 (vs ~0.00 when
sampling), and the human in the 08-28 session presses d_up **0.00**
times/min. The dominant bot pathology is named and counted:
`GRAB_WAIT>GRAB_PUMMEL`, 78/94/16 episodes across the three corpora,
outnumbering all other cycles combined.

Caveats recorded there: raw loops/min is NOT a pathology score (the
human "loops" more, because dash-dancing is a cycle — rank by specific
pattern); and this axis measures COST, not competence, so it pairs with
the 0827 finding that colder buttons trade passivity for deaths.

**Consequence for §6:** the AWBC arms now have a scoring instrument that
survives its own reproducibility check. Score B1/B2/B3 on this axis
alongside `coach_report`, not on armed/min alone.
