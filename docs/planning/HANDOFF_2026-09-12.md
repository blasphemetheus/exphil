   it is 45/min c3. Every ms card before 09-10 was an argmax number.
   `gate_sweep.sh` samples by default now (`GATE_TEMP=0` = argmax).
2. **Under sampling, convergence is the lever**, not the ep-4 peak:
   g19 late epochs chain 9-12 (loss 0.010). The peak/decay lore was
   the argmax metric.

   aerial reflector (p 0.33); argmax makes it worse. Mechanism unknown
   (instrument #4 below). Independent head is decisive (0.91-1.0).

   decision. Per-state probe: `scripts/probe_ms_state_confidence.exs`.

   pool to 5e-5 yet sat at 0.95 on two boundary frames. Found:
   `snippet_mine.exs` built its expert table from `closed.slp` while the
   drill uses `closed_d1.slp` (one frame earlier) — 12.5k snippet
   frames one frame off at the boundaries, in g19's pool too. Re-mined
   -> g23a ep57: 0.98 on the boundary frames, chains 438/4/423.
   `--action-frame-buckets 24` (now drill-wired) took the loss floor
   5e-3 -> 5e-5 but did not move chains by itself.

## 3. NEXT — the interp instruments (Bradley: "let's start down this list")

1. **Pool label-conflict auditor as a PRE-TRAIN GATE.** Extend
   `scripts/probe_ms_label_dilution.exs`: entropy of training labels per
   state key (action, af, grounded + opponent buckets + prev-input
   queue) over the assembled pool (fixture, rollouts relabeled,
   snippets, openers, scramble). Refuse to train where the pool
   disagrees with itself on a loop state. Seconds; would have caught
   the snippet conflict before g19.
2. **Counterfactual coverage map** (the goal, measured offline): perturb
   fixture loop states along own position / opponent position /
   opponent action / facing / percent; batch-embed; p(correct input)
   per cell. Aims DAgger rollouts instead of collecting blind.
3. **Chain-break attribution**: per break in a rollout, teacher-forced
   replay of the window, p(correct) at the break frame, gradient x
   input over embedding groups (own, opponent, prev-action queue,
   delay-id). Needs Activations/attribution + CycleSim to support the
   queue/delay-id layout (that repair also gives an offline chain
   predictor).
4. **AR-head conditional entropy along the chain** at loop states —
   the mechanism behind g20a's mid-air release; needed before the AR
   head is declared unfit, since verifying it is the point.
5. **Re-entry profile** after a break (frames to next JC, which state it
   parks in) — the absorber-entry detector with the ms embed config.
