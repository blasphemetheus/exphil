## 5. Gotchas / operational law (new; older in HANDOFF_2026-09-03 §5, GOTCHAS.md #108-111)

- **bptt loss scale ≠ windowed loss scale** (per-timestep vs
  last-frame): 6.x vs 5.x is NOT a regression. Compare bptt to bptt.
- **bptt streaming branch bypasses ChunkPipeline**: no prefetch, no
  embedding cache — re-embeds every epoch. Fine for shakeouts; a v2
  run wants caching added (or accept ~30% overhead).
- **The bptt branch needs >= batch_size segments per stream chunk**
  (TrajectoryCursors raises otherwise): batch 128 -> chunk >= 200
  files.
- **Registry semantics**: built from TRAIN files only (val holdout
  split first); cache key includes the registry mapping (stale-hit
  guard is tested — don't remove it).
- **`hf download`**: repeated `--include` flags, never multiple
  patterns after one flag (argparse eats them as positional
  filenames); char-dir sizes are ~10x a batch-dir estimate; xet cache
  can double payload on ~/.cache (delete after).
- **Drive pulls via rclone**: remote `gdrive:` +
