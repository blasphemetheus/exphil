## THE TWO DISCOVERIES OF 08-07/08

1. **Opponent-character is the fight-state wall, and it's augmentable.**
   First non-Fox human opponent ever faced (Bradley's Mewtwo) collapsed
   multishine from chain 58 (still Fox) to 1 (still Mewtwo) — same
   silencing mechanism as the platform absorber. Four augmentation
   rounds mapped the design space:
   - g13 (coherent redress, smallest-first, no Fox in roster):
     **INVERTED** the policy (Mewtwo c22, Fox c1!) — data-quality/
     character confound. Kept as a forensics specimen.
   - g13b (confound fixed): conditioning, not invariance — dependence
     ROSE. Coherent redress teaches costume-switching.
   - g14 (per-frame scramble, 3 fields): **dependence floor 1.08 +
     stand record** — in-support noise teaches true ignoring — but no
     transfer (unmasked fields still gate).
   - g15 (full-block scramble): record core + REAL Mewtwo transfer
     live, but dependence ceiling 4.28 — implausible noise teaches
     scramble-DETECTION. **Mask plausibility is the design variable**;
     the sweet spot (subtle noise, full coverage) is unexplored.
2. **The full-game IL harness is VALIDATED.** fox_il_v1 (900 HF games,
   5.4M frames, stride 30, GRU): val 5.49→4.95 monotone in 10 epochs
   (~25 min), and the exported policy completes live games vs a CPU
   with 42 distinct actions and full-stage movement (loses 2 stocks,
   takes 0 — varied-and-bad, exactly v1). The
   representation question that motivated the multishine program is
   answered YES at full-game scope.

## ADDENDUM 2026-08-08 #6: incremental mmap corpus SHIPPED — fox_il_v2 unblocked

Engineering item #1 (the full-corpus unlock) is built, tested, and
running:

- **`ExPhil.Training.MmapCorpus`** (lib/exphil/training/mmap_corpus.ex,
  9 tests): incremental writer (parse→embed→append per file, headers +
  manifest patched per append = crash-safe/resumable), reader (labels
  packed 6 bytes/frame in RAM — the ~50GB frames-list problem was only
  ever about label lookup; embeddings stay on disk, one contiguous
  pread per window), and a batch stream emitting the same
  `%{states, actions, frame_weights}` maps as the lazy in-RAM path.
  Sequence windows are generated per file range — they never cross a
  game boundary (the in-RAM lazy path silently allows this).
- **`scripts/build_corpus.exs`**: resumable builder. Fixes a v1 data
  bug en route: v1 parsed player_port 1 ALWAYS, so every game with Fox
  on port 2 trained on the OPPONENT's controls; the builder picks the
  Fox port per file from metadata (`--character fox`, port recorded in
  the manifest).
- **`--corpus DIR` on train.exs** (Config + Pipeline corpus mode):
  skips parse/embed entirely, val split = whole-file holdout,
  button_pos_weight :auto served from packed labels. Temporal only.
- Validated end-to-end: 20-file smoke corpus (179k frames, 13s) →
  1-epoch GRU train → policy export, val 6.997.

Full build launched: `replays/fox_il_v1` → `cache/corpus/fox_v2`
(4,465 files @ ~1.5 files/s ≈ 50 min, ~41M frames / ~47GB — the 28M
estimate undercounted; log eval_runs/0808_build_corpus_fox_v2.log).
Next: fox_il_v2 = `mix run scripts/train.exs --corpus
cache/corpus/fox_v2 --backbone gru --window-size 60 --stride 30
--batch-size 64 --epochs 10 --name fox_il_v2`, then the
behavior-eval protocol item.

## ADDENDUM 2026-08-09 #7: fox_il_v2 TRAINED — full corpus, 49 minutes

The corpus paid off immediately. fox_il_v2 (GRU w60 s30 b64, 10 epochs,
`--corpus cache/corpus/fox_v2`): **val 5.687 → 5.374 MONOTONE, still
descending at epoch 10** (constant LR; more epochs are free — each is
~5 min). Whole-game holdout: 442 files / 2,211 val batches. Wall time
49 MINUTES for 10 epochs over 41.4M frames — the mmap batch path runs
~25ms/it at GPU 61%, disk is not the bottleneck. RAM flat.

Artifacts: `checkpoints/fox_il_v2_20260809_041730*` (best_policy.bin =
the deploy file; registry name double_jumping_pummel).

**v1-vs-v2 val numbers are NOT comparable** — the port audit shows only
38% of corpus games have Fox on port 1 (1663/831/840/1084 across ports
1-4), so v1's fixed-port parse trained on wrong-player or missing-player
data in 62% of its files AND validated on the same pollution. v2 is the
first clean full-game IL number.
