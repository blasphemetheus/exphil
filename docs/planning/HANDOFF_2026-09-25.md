### 4.1 The Mewtwo result, and why the win rate is the least useful part

Full tables in `HANDOFF_2026-09-24b.md` §4b/§4c. The conclusions:

- **`head_iter150`: 199W/1L = 99.5 %** (Wilson CI 97.2–99.9) on 200 games at

- **The number that matters: deaths/min fell 4.03 → 1.25 (−69 %) while kills/min

  touched the other half. Report it this way, not as "99.5 %".

  went 60W/0L in selection. The instrument can no longer separate two heads, nor
  separate "better at Melee" from "found something this one opponent cannot
  answer". **Decision: an opponent pool is now a prerequisite, not an
  improvement, for any further RL claim on either character** — and this

  saturated. `opponent_pool.ex` exists; RL_ON_PRIOR's design section already

- **Exploit hypothesis: live but weakened, and both sides are recorded.** For:

### 4.3 The Mewtwo critic beat Fox's, and stride is why

Mewtwo R2 **PASSED at test EV 0.61** (stride 6, hidden 256, wd 0.001, dropout 0)
on a round the epoch selection never saw — roughly double Fox's 0.314.

The refit selecting **stride 6** (every 6th frame) is the transferable lesson:
at 60 Hz adjacent frames are near-duplicates, so training on all of them
memorizes. Fox's first attempt reached train EV 0.913 / held-out 0.037.
Discarding 5/6 of the data made the critic better.

Plausible reason Mewtwo's is higher: this prior dies constantly and
predictably, so its states are far more informative about the next stock.

### 4.4 Character parameterization: the flag was trivial, the provenance was the point

`--character` (validated, default `fox`) now exists on `ppo_r3.exs`,
`critic_r2.exs`, `ppo_eval.exs`, `ppo_r3_eval.exs`. Each was a single hardcoded
`players = [%{character: "fox", …}]` literal.

The real work was making silent cross-character mistakes impossible, because
those are the ones that produce believable wrong numbers:

- character/stage/seed persist into `log.json`, `head_iterN.bin`, `critic.bin`;
- `critic_refit.exs` forwards them into `critic_best.bin`;
- **`ppo_r3.exs` refuses a critic fit on a different character** (and warns when
  a critic carries no provenance at all);
- **`ppo_r3_eval.exs` defaults to the head's own recorded character**, so a
  Mewtwo head cannot be graded in a Fox ditto.

## 6. Gotchas / operational law

**Learned this session** (also written into `docs/reference/GOTCHAS.md` as #125
and #126):

- **`ExPhil.Bridge.SimBatch` is the GenServer; the lookup tables live in
  `ExPhil.Bridge.SimBatch.Core`.** `sim_batch.ex` defines `.Core`;
  `sim_batch_server.ex` defines `SimBatch`. File names and module names disagree
  in both directions. A `def` added to the wrong one compiles clean and is
  undefined at the call site. Fixed by `defdelegate`.
- **Sim `char_id` IS the game's internal fighter kind — identity mapping, no CSS
  conversion on this path** (`sim_state.ex` moduledoc). Mewtwo is 16 on both
  sides. And `state.players[p].character` is a plain **integer**, not an atom.
- **A wrong assertion is indistinguishable from a wrong system.** My first
  Mewtwo admission probe failed because it asserted an atom. The sim was correct.
  Check the representation before believing a red check.

**Standing law, easy to forget, expensive to relearn:**

- **A multi-stage chain runs a fresh `mix run` per stage, and each invocation
  recompiles changed `.ex` files.** Editing a lib file while a chain is live
  injects it (or a compile error) into the next stage — this killed round-4
  probes and round-5 training on 2026-07-15. While any chain runs: edit only
  `.exs` scripts it does not call, docs, or other repos.
- **One EXLA process on the GPU at a time.** A second client SIGSEGV/SIGBUSes any
  live beam. Check `systemctl --user list-units 'exphil-*'` and the coordination
  log first.
- **`scripts/launch_unit.sh UNIT '<cmd>'` for anything long.** `systemd-run
  --user` starts in `$HOME`, so a bare relative command dies instantly with no
  log. This bit four times on 09-22.
- **`:erlang.term_to_binary` on GPU-resident tensors writes a file that cannot be
  decoded back** ("none of the variant types could be decoded"). Always
  `ExPhil.Training.PPO.to_binary_backend/1` first. This killed a control run.
- **`devenv shell` from the repo root**, then plain `mix`. No nix-shell.
- **`--replay-dir` on every live run** (GOTCHA #84): without it replays land in
  Dolphin's temp dir and the evidence is destroyed.
- **No `perl`/`sed` pipe-delimiter regex edits on code**; no Python for edits.
  Use the Edit tool or Elixir.
- Never crown on stand-dummy or single-opponent numbers (the g6 lesson).
- Do not edit files the other agent lists under OWNS without claiming them first.
