Where does the bot leave value on the table?

Every dot is a real state the policy reached against itself. From each one it sampled 64 continuations; the color is how many of them converted an opening into a second hit. The oracle picks the best of the 64, so nearly every start has a converting line somewhere in the policy. Regret is the gap between what it could do and what it usually does.
